# Panduan Pengumpulan Tugas

1. Ekstrak `Python_Dasar_Tugas.zip`.
2. Pastikan folder berisi README, 11 folder bab, `requirements.txt`, dan file `nilai.csv`.
3. Buka beberapa file `.py` di VS Code dan jalankan untuk memastikan program berjalan.
4. Unggah folder ke Google Drive atau buat repository GitHub.
5. Jika memakai Google Drive, ubah akses menjadi dapat dilihat oleh dosen (sesuai kebijakan kampus).
6. Salin tautan folder/repository.
7. Tempel tautan tersebut di kolom pengumpulan e-learning.

## Perintah uji yang disarankan
```bash
python Bab_01_Pengenalan_Python/pengenalan.py
python Bab_02_Variabel_Tipe_Data/variabel_tipe_data.py
python Bab_03_Input_Output/input_output.py
python Bab_04_Operator/operator.py
python Bab_05_Percabangan/percabangan.py
python Bab_06_Perulangan/perulangan.py
python Bab_07_Koleksi_Data/koleksi_data.py
python Bab_08_Function/function.py
python Bab_09_Error_Handling/error_handling.py
python Bab_10_Module_Package/main.py
python Bab_11_Pengolahan_Data/olah_data.py
```

Bab 03 dan Bab 09 meminta input. Untuk Bab 09, coba angka biasa, `0`, dan teks untuk melihat penanganan error.
